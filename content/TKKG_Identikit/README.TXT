1. General Information
======================

You should close all other applications before starting the CD-ROM.
This way the program runs much quicker. 

The CD-ROM must always be in the CD-ROM drive during the game. 

Please note that your computer must meet the following minimum requirements
in order to run this game: 

Windows: 
WIN 95/98/NT, Pentium 100, 16 MB RAM, sound card, 16-bit high colour, 
30 MB of free hard disk space 
 
Macintosh: 
Power PC, 24 MB RAM, System 7.5, 32768 colours, 30 MB of free hard disk
space

=============================
2. Installation of the CD-ROM
=============================

You should note the following during the installation:

Windows:
The installation programs will start automatically, when you insert the
"Identikit Program" CD-ROM into the CD-ROM drive.

If the "Autostart" function in Windows has been deactivated, you can start
the CD-ROM in the following way: 
In the "File" menu, choose the "Run" command and then enter "X:\Install.exe".
Type the designation of your CD-ROM drive in place X. Click on "OK" and then
follow the instructions on the screen. 

By the way: You can delete all installed files from your hard disk whenever
you like with the Uninstall program. To do this click on the icon 
"Delete Identikit" in the Tivola game folder, and then follow the 
instructions given.


Macintosh:
A window will automatically open after inserting the "Identikit Program" 
CD-ROM into the CD-ROM drive. Copy the folder "Identikit" onto your
hard disk. When you click on the icon "TKKG Identikit" that is in this
folder, the game will start. 

In order to delete the program from your hard disk, drag the "TKKG Identikit"
file from the hard disk into the waste paper basket.
